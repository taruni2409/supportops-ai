# NovaBank Identity Verification Policy

## 1. Identity Verification Required

NovaBank may require identity verification before certain account actions or
support procedures can be completed.

Customers should provide only the documents requested through approved NovaBank
verification channels.

Support agents should not request identity documents through unapproved
communication channels.

## 2. Verification Failed

If automated identity verification fails, the customer should first confirm that
the information submitted matches the information registered on the account.

Documents should be clear, valid, and readable.

Repeated verification failures should be escalated to the Identity Verification
team for manual review.

## 3. Name or Personal Information Mismatch

If the customer's submitted identity information does not match the account
information, support agents should determine whether the mismatch is caused by
an error or a legitimate change in personal details.

The customer may be required to provide supporting documentation through an
approved verification process.

Support agents should not directly modify verified identity information without
following the approved account-update procedure.

## 4. Verification Escalation

Identity-verification cases should be escalated when automated verification
fails repeatedly, submitted documents cannot be validated, or account
information contains unresolved inconsistencies.

Support agents should record the reason for escalation and the verification
steps already attempted.
